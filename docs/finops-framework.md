# FinOps Framework Coverage

How this toolkit maps to the three phases of the FinOps framework.

## 1. Inform (visibility, allocation, reporting)

- Automated email reports with tag-based breakdown
- Cost analysis by tag value and service
- Anomaly detection
- Multi-account consolidation via AWS Organizations (per-account breakdown)
- Historical storage in Amazon S3

## 2. Optimize (identify and execute opportunities)

- Cost Optimization Hub recommendations (rightsizing, purchasing)
- Trusted Advisor cost checks (requires Business/Enterprise Support)
- Compute Optimizer analysis (EC2, Lambda, EBS)
- Consolidation and prioritization of opportunities by potential savings

## 3. Operate (governance and standardization)

- Tag compliance validation across regions
- Tag inventory with similar-tag (typo) detection

## Coverage summary

| Phase    | Coverage |
| -------- | -------- |
| Inform   | High     |
| Optimize | High     |
| Operate  | Medium   |
